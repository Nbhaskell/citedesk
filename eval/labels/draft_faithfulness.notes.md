# Notes while labelling

Free-text notes about drafts, kept apart from the labels file so they cannot change a label.
Write one line per draft: the id from the sheet, then what you noticed. Ids and notes only (no
message text). Examples of what is worth a line:

- would not send as it is (say why in a few words)
- had the answer in the passages and did not give it
- asks for something the message already said
- tone reads oddly
- label was a judgment call (say which two labels you hesitated between)
